# Market site — translation glossary (terminology consistency)

These are the canonical translations for key terms. Use them consistently in the
per-country editorial content (overview / considerations / faq / evNote / suvNote).
Numbers, rates, currency codes, port names, authority acronyms (e.g. KRA, ZATCA,
SASO, GSO, BOI) and vehicle-model names are **never translated** — keep them as in
the English source.
